# 力的正负方向判断

## 核心规则
先建立**右手直角坐标系**，再判断：

- 力的箭头与坐标轴**正向同向** → **正**
- 力的箭头与坐标轴**正向反向** → **负**

## 未知力的处理
画受力图时，未知反力可先**任意假设方向**（通常按坐标正向画）。

- 算出结果 > 0 → 实际方向与假设一致
- 算出结果 < 0 → 实际方向与假设**相反**

## 示例
假设右手系：$x$ 向右，$y$ 向前，$z$ 向上。

| 力的情况 | 投影符号 | 说明 |
|---------|---------|------|
| 沿 $+x$ | $F_x = +F$ | 正 |
| 沿 $-x$ | $F_x = -F$ | 负 |
| 沿 $+z$ | $F_z = +F$ | 正 |
| 沿 $-z$（重力） | $F_z = -W$ | 负 |

**注意**：坐标系方向可自定，但一旦定好必须全程统一。
