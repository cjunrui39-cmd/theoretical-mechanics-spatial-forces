# 空间力系与平衡方程

## 空间任意力系平衡条件
物体在空间任意力系作用下平衡的充分必要条件是：
- 主矢 = 0
- 对任一点的主矩 = 0

解析形式（右手直角坐标系）：

$$
\begin{cases}
\sum F_x = 0 \\
\sum F_y = 0 \\
\sum F_z = 0 \\
\sum M_x = 0 \\
\sum M_y = 0 \\
\sum M_z = 0
\end{cases}
$$

共 6 个独立方程，可解 6 个未知量。

## 列方程步骤
1. 取研究对象，画完整受力图（FBD）
2. 建立右手直角坐标系（原点尽量选在未知力较多的点）
3. 假设未知力/力矩的正方向（通常沿坐标正向）
4. 列 6 个方程
5. 解方程，负号表示实际方向与假设相反

## 特殊情况
- **空间汇交力系**：只需 3 个力投影方程
- **空间力偶系**：只需 3 个力矩方程
- **空间平行力系**：减少方程数
